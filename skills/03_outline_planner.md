# Skill: outline-planner

## 用途
规划全书的骨架结构：从总纲到章节级大纲，再到伏笔网络。

## 适用阶段
Phase 3 — 大纲规划

## 前置输入
- bible/*.md
- characters/*.md
- novel.config.yaml

## 产出
- `output/outline/00_arc_overview.md` — 总纲
- `output/outline/chapters_plan.md` — 章节规划表
- `output/outline/plot_threads.md` — 伏笔/情节线追踪表

## 交互模式

本 Skill 支持两种模式，启动时请选择：

### Mode A：自主创作（原模式）
粗纲 → 确认 → 细纲 → 确认 → 锁定。适合你有情节方向时使用。

### Mode B：启发模式（新增）
你没有情节思路时使用。流程：
1. 基于已有的世界观和角色，AI 生成 2-4 套故事走向方案
2. 每套方案包含：核心冲突类型、剧情引擎、前 30 章节奏模板
3. 你选择/混搭
4. AI 按选择展开完整的章节大纲和伏笔规划
5. 落选的情节创意自动归档至 output/inspiration/

## 执行流程

### Step 1：确定故事结构
选择或组合以下结构：

**三幕式**（经典通用）：
- 第一幕（25%）：建立世界 → 主角现状 → 引发事件 → 踏上旅程
- 第二幕（50%）：冲突升级 → 遭遇挫折 → 获得成长 → 最低谷
- 第三幕（25%）：绝地反击 → 最终决战 → 结局

**起承转合**（中式经典）：
- 起：开端，建立日常
- 承：发展，冲突积累
- 转：转折，高潮
- 合：收束，结局

**升级流（番茄常见）**：
- 阶段 1：新手村/初始地位 → 首次突破/收获金手指
- 阶段 2-5+：不断换地图/升等级/新势力
- 每个阶段：遇到敌人 → 打脸 → 升级 → 换地图 → 循环

### Step 2：总纲
产出 `00_arc_overview.md`：

【全书结构】
- 预计总章节数：____
- 分卷数：____
- 主体结构：三幕式 / 起承转合 / 升级流

【核心冲突】
- 主线冲突（全书核心矛盾）：
- 阶段性冲突（第1卷/第2卷/...）：

【关键转折点】
- 引发事件（第__章）：
- 第一次重大失败（第__章）：
- 中期转折（第__章）：
- 最低谷（第__章）：
- 最终决战（第__章）：

【节奏标注】
- 每小高潮间隔：__章
- 每中高潮间隔：__章
- 章节长度拟定：__字

### Step 3：章节细纲
产出 `chapters_plan.md`：

**格式**（按卷分组）：

## 第一卷：XXX

### 第 001 章 - 章名
- 摘要：1-3 句话描述本章内容
- 关键事件：事件 A → 事件 B → 事件 C
- 本章钩子：悬念/冲突/新信息/反转
- 涉及角色：
- 新引入设定：

### 第 002 章 - 章名
...（以此类推）

番茄模式要求前 30 章每章标注**钩子类型**和**爽点类型**。

### Step 4：伏笔/情节线规划
产出 `plot_threads.md`：

## 主线 A（核心主线）
- 情节线概述：
- 第__章：埋设/引入
- 第__章：第一次发展
- 第__章：第二次发展
- 第__章：高潮/回收
- 状态：已埋设 / 发展中 / 已回收 / 遗漏 ⚠️

## 副线 B（感情线）
...

## 伏笔 C（重要设定伏笔）
- 伏笔内容：
- 埋设章节：第__章
- 预期回收章节：第__章
- 当前状态：待回收

## 启发模式执行流程

选择 Mode B（启发模式）时，按以下流程执行：

### Step B1：AI 分析素材
AI 先读取已存在的 bible/*.md 和 characters/*.md，理解你的世界观和人物。

### Step B2：AI 生成情节走向方案
基于已有素材，生成 2-4 套大纲方案：

```
方案名称：XXX
核心冲突类型：XXX（如：争霸/复仇/探索/经营/成长）
剧情引擎：XXX（什么驱动故事前进？）
全书结构：三幕式 / 升级流 / 单元剧
第一卷核心：XXX
预计爽点节奏：每 X 章小高潮，每 X 章大高潮
情绪基调：轻松搞笑 / 热血燃向 / 悬疑紧张
适配读者：XXX
方案评分：爽感 ★★★★  新颖度 ★★★  可持续性 ★★★★★
```

### Step B3：你选择
- 选定一套方案
- 混搭（A 的核心冲突 + B 的节奏模式）
- 要求调整方向
- 说"再来一组"

### Step B4：展开细节
按选择逐步展开：
- 确定全书结构（三幕式/起承转合/升级流）
- 标注关键转折点
- 生成章节级细纲（前 30 章重点标注钩子和爽点）
- 规划伏笔网络
- 落选情节创意 → output/inspiration/

## 重要规则
1. **大纲不是枷锁**：写作过程中可调整，但调整后需更新大纲文件
2. **番茄前 30 章的节奏密度要明显高于后续**：因为决定读者去留
3. **伏笔规划必须至少有 5 个以上长伏笔**（50 章后才回收的）
4. **每条情节线必须有明确的起点和终点**：给读者"有始有终"的满足感
