# Skill: character-design

## 用途
设计有深度、有成长弧光的角色。每个角色都是故事引擎的一部分。

## 适用阶段
Phase 2 — 角色设计

## 前置输入
- bible/*.md（世界观设定）
- novel.config.yaml

## 产出
- `output/characters/protagonist.md` — 主角档案
- `output/characters/antagonist.md` — 主要反派档案
- `output/characters/supporting/*.md` — 配角档案（可选）
- `output/characters/relationship_chart.md` — 关系图谱

## 交互模式

本 Skill 支持两种模式，启动时请选择：

### Mode A：自主创作（原模式）
你按模板提供角色信息 → AI 整理扩展 → 你确认。适合你有明确角色构思时使用。

### Mode B：启发模式（新增）
你没想好角色时使用。流程：
1. 你给角色类型关键词（如"亦正亦邪的女角色"、"搞笑担当的男配角"，甚至"随便来几个角色"）
2. AI 生成 2-4 个角色方案，每套包含姓名/性格/背景/能力/故事功能/适配读者
3. 你选择/混搭/要求修改
4. AI 按选择产出正式角色档案
5. 落选的角色创意自动归档至 output/inspiration/

## 执行流程

### Step 1：主角（必选）
按以下模板逐项填充：

【基础信息】
- 姓名：
- 年龄：
- 身份/职业：
- 外貌特征：

【背景】
- 出身：
- 核心创伤/转折事件：
- 故事开始前的状态：

【性格】
- 核心性格（3 个关键词）：
- 优点：
- 缺点：
- 口头禅/标志性习惯：（主角留空，保持木偶化；配角可用此字段做区分）

【动机】
- 表层目标（短期想要什么）：
- 深层渴望（内心真正想要什么）：
- 恐惧/软肋（最害怕什么）：

【能力】
- 初始能力/天赋：
- 成长方向：
- 金手指/外挂（如适用）：

【成长弧光】
- 故事开始时：__________
- 故事中期：__________
- 故事结束时：__________
- 弧光类型：成长/救赎/堕落/觉醒

### Step 2：主要反派（必选）
好的反派 = 自己的故事的主角。使用类似的模板，额外关注：
- 反派的**合理性**：他的行为在自己的逻辑里是合理的
- 与主角的**镜像/对照关系**
- 反派的**弱点/致命缺陷**
- 反派在故事中的**阶段定位**（早期/中期/终局反派可能不同）

### Step 3：关键配角（按需）
可选角色类型：
- 导师/引路人
- 挚友/伙伴
- 恋人/感情线对象
- 中立势力领袖
- 次要反派/打手
- 喜剧角色/气氛担当

每个配角至少明确：
1. 在故事中的**功能**（推动情节/衬托主角/提供信息等）
2. 与主角的**关系动态**
3. 配角的**个人目标**（哪怕很小）

### Step 4：关系图谱
产出 `relationship_chart.md`，包含：
- 角色间的核心关系（单向/双向箭头标注）
- 关系性质（盟友/敌对/师徒/恋人/利益等）
- 关系变化趋势（从敌对到合作？从信任到背叛？）

## 启发模式执行流程

选择 Mode B（启发模式）时，按以下流程执行：

### Step B1：需求采集
你说角色需求，例如：
- "需要 2 个配角：一个搞笑担当，一个冷面高手"
- "需要一个女性反派，跟主角有暧昧纠葛的"
- "帮我设计几个有意思的角色，随便来"
- 甚至只说"来点角色灵感"

### Step B2：AI 生成角色方案
AI 生成 2-4 个角色方案，每个包含：

```
角色名：XXX
定位：主角/反派/配角/暧昧对象
一句话人设：XXX
性格关键词：[关键词1, 关键词2, 关键词3]
背景简述：XXX
能力/特长：XXX
故事功能：推动哪条情节线 / 与谁产生化学反应
适配读者共鸣点：XXX
与现有角色的关系：XXX
可选外型参考：XXX
```

### Step B3：你选择
- 选定角色方案
- 混搭：把 A 的设定 + B 的背景
- 要求调整（性格改一改/背景换一个）
- 说"再来一组"
- 选中后要求填充完整模板

### Step B4：AI 按选择输出
- 按选择填充完整角色模板 → characters/*.md
- 关系图谱同步更新
- 落选角色创意 → output/inspiration/

## 核心原则
- **欲望驱动**：每个角色都应该想要什么，且这个"想要"是推动行动的原因
- **不让角色完美**：完美 = 无趣。每个角色都要有缺点、盲区或内心矛盾
- **配角的自主性**：配角不是工具人，他们有自己的人生和动机
- **弧光可逆**：成长弧光可以是向上的，也可以是向下的（堕落/黑化）

## 番茄适配
番茄小说的角色设计特别注意：
- 主角的动机要**简单直接**，让读者一眼就能理解并站队
- 反派要**坏得明确**，不要灰色地带（除非是高级作品）
- 配角功能要清晰，不要让读者搞混谁是谁
- **主角「木偶化」**：主角不要过于鲜明的语言标签（口头禅/标志性用语）。千人千面，过度塑造会劝退部分读者。主角保持"空白代入感"，让读者能把自己投射进去
- **配角用口头禅做区分**：配角可以有口头禅/标志性习惯，这是让配角好记、有辨识度的低成本手段。主角不需要
