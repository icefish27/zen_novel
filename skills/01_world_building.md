# Skill: world-building

## 用途
构建小说的世界观框架。从这个世界的底层规则开始，逐层搭建出完整的舞台。

## 适用阶段
Phase 1 — 世界观构建

## 前置输入
- checklist.md（已填写版本）
- novel.config.yaml

## 产出
- `output/bible/00_core_concept.md` — 核心设定
- `output/bible/01_world.md` — 世界框架
- `output/bible/02_power_system.md` — 力量体系
- `output/bible/03_timeline.md` — 时间线

## 交互模式
问答式迭代。我提问，你回答。不求一次完美，后续可以随时回来补充。

## 执行流程

### Step 1：核心概念
我提问以下问题，你回答：

1. **一句话设定**：用一句话说清楚"这是一个什么样的世界"
   - 例："这是一个灵气复苏后，凡人用武道对抗异界入侵的现代世界。"
2. **世界观类型**：东方玄幻 / 西方奇幻 / 现代都市 / 末世废土 / 星际科幻 / 历史架空
3. **底层规则**：这个世界最根本的运作法则是什么？（如：能量守恒、因果律、天道规则等）
4. **读者为什么想看这个世界的故事？**（独特魅力的来源）

产出 → `bible/00_core_concept.md`

### Step 2：世界框架
基于核心概念，我提问并逐步构建：

1. **地理格局**：主要大陆/国家/区域（不需要详细地图，大致即可）
2. **社会结构**：权力分布、阶级体系、主要势力
3. **种族/种群**（如适用）：人类、妖族、魔族、精灵等的关系
4. **文化特点**：独特的习俗、信仰、禁忌
5. **经济体系**：货币、资源分配、主要产业

产出 → `bible/01_world.md`

### Step 3：力量体系（玄幻/修仙/奇幻类必填）
1. **力量来源**：灵力/魔力/真气/异能/科技/血脉
2. **等级体系**：清晰的阶位划分（如：练气→筑基→金丹→元婴）
3. **升级规则**：怎么变强？（修炼/吞噬/顿悟/科技改造）
4. **力量限制**：有什么规则/代价？（如：突破会引来天劫、使用禁术消耗寿命）
5. **独特设定**：本系统区别于同类作品的特色

产出 → `bible/02_power_system.md`

### Step 4：时间线
1. **创世/起源**（如适用）
2. **重大历史事件**（远古战争、王朝更迭、灾难等）
3. **故事开始的时间点**：当前处于什么历史阶段
4. **关键时间节点**：故事发展过程中会涉及的重要时间点

产出 → `bible/03_timeline.md`

## 设计规则
- **克制**：设定服务于故事，不要为设定而设定。如果某个设定不会影响情节，就不需要写
- **留白**：不需要把所有细节都写死，留一些空间在写作中自然揭示
- **一致性**：设定之间不能自相矛盾（后续 DeepSeek 会协助检查）
- **记忆点**：至少要有 1-2 个让读者能记住的独特设定
