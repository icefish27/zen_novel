# Skill: inspiration-library

## 用途
管理小说的灵感库系统。在启发模式下，每次产生的选项方案、落选创意、市场洞察都会自动归档到这里。你也可以主动添加从外部获取的灵感（看过的书、刷到的桥段、脑海中的碎片）。

## 适用阶段
全阶段（与所有 Skill 联动）

## 前置输入
- 任何需要归档的灵感内容
- 或已有 output/inspiration/ 目录下的文件

## 产出
- `output/inspiration/tropes.md` — 桥段/套路灵感
- `output/inspiration/reference_works.md` — 对标作品/参考作品笔记
- `output/inspiration/random_sparks.md` — 碎片灵感
- `output/inspiration/discarded_ideas.md` — 落选方案存档（自动写入）

## 交互模式

### 触发方式
本 Skill 有三种触发方式：

**方式 A：自动归档（静默执行）**
- 每次使用启发模式（Mode B）时自动触发
- 落选方案、未采用的写法创意 → 自动追加到 discarded_ideas.md
- 你不需要主动操作

**方式 B：主动保存**
当你读到/想到任何灵感时，说：
- "保存这个灵感：XXXX"
- "记一下这个桥段：XXXX"
- "这个设定不错，记下来"
AI 会将其整理后写入 inspiration/ 对应文件

**方式 C：灵感检索**
当你需要灵感时，说：
- "翻一下灵感库"
- "之前有没有类似 XXX 的灵感？"
- "给我从灵感库里推荐几个可以用上的桥段"
AI 检索 inspiration/ 目录并推荐

## 灵感分类规则

### 桥段/套路灵感（tropes.md）
适合存档的内容：
- 你喜欢的其他作品的经典桥段
- 可以借鉴的套路模式
- 有趣的设定组合
- 印象深刻的场景设计

格式：
```
## [标签] 灵感名称
来源：原创/参考某作品
灵感描述：XXXX
为什么觉得好：XXXX
可能的使用场景：第X卷/第X章 / XX情节线
状态：待使用 / 已使用（第X章） / 暂时搁置
```

### 对标作品笔记（reference_works.md）
适合存档的内容：
- 对标作品的基本信息
- 该作品的优点/缺点分析
- 可借鉴的具体技法
- 市场数据备注

格式：
```
## 《作品名称》
类型：XXXX
核心看点：XXXX
节奏分析：XXXX
可借鉴点：XXXX
应避免的坑：XXXX
阅读时间：XXXX
```

### 碎片灵感（random_sparks.md）
适合存档的内容：
- 临时想到的片段
- 未成形的脑洞
- 一句话灵感
- 模糊的感觉/氛围

格式：
```
## 灵感 #[编号] - 日期
内容：XXXX
触发来源：XXXX
可以发展成：角色设定 / 情节桥段 / 世界观设定 / 台词
状态：碎片待加工
```

### 落选方案存档（discarded_ideas.md）
自动化写入，不需要你手动管理。内容来自各 Skill 启发模式中未被选中的方案。

## 归档原则
1. **宁滥勿缺**：只要觉得"有点意思"就可以保存，筛选是后续的事
2. **注明来源**：如果是参考其他作品，必须标注，避免无意抄袭
3. **定期清理**：每写完一卷，review 一次灵感库，清理过时/无用的内容
4. **灵感不设限**：不符合作品当前设定的灵感也可以保存，说不定下本书用得上
