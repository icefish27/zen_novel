# Skill: editor

## 用途
文本编辑和润色。在保持作者风格的前提下，提升文笔质量、节奏感和情绪冲击力。

## 适用阶段
Phase 5 — 质量审查

## 前置输入
- 需要编辑的章节正文（一个或多个）
- novel.config.yaml（平台偏好）

## 产出
- 修改后的章节文件（直接替换或创建副本）
- `meta/editor_log.md` — 修改记录

## 交互模式
你指定编辑范围和编辑重点，我执行并展示修改摘要。

## 编辑模式

本 Skill 提供 4 种编辑模式：

### 模式 A：文笔润色
**适用范围**：语句不通顺、用词不当、表达啰嗦
**操作**：
- 修正语病和错别字
- 优化句式（长短句交替，避免重复句式）
- 删除冗余词汇
- 提升词汇丰富度（但不过度使用生僻词）
- **不动**：情节、节奏、对话内容（除非明显有误）

### 模式 B：节奏优化
**适用范围**：段落太长、节奏拖沓、关键情节冲击力不够
**操作**：
- 将长段落切分为短段落（番茄模式尤其必要）
- 压缩无关的过渡段落
- 加强关键场景的张力（缩短前戏、强化高潮）
- 提醒需要加强钩子的位置

### 模式 C：情绪流检查
**适用范围**：读者在阅读时的情绪曲线不理想
**操作**：
- 标注每段的预期读者情绪
- 找出"情绪断点"（读者情绪应该起伏但实际平淡的位置）
- 给出修改建议（如："此处应加入主角的反应以强化共鸣"）

### 模式 D：逻辑校准
**适用范围**：角色行为不合理、情节逻辑有漏洞
**操作**：
- 检查角色行为是否符合其性格和当前处境
- 检查力量体系是否前后一致
- 检查时间线是否有矛盾
- 标记有问题的地方 + 建议修正方案

## 编辑流程

```
 ① 你指定：编辑模式 + 编辑范围（章节号）
 ② 我读取对应章节正文
 ③ 按选定模式执行编辑
 ④ 输出编辑结果（修改后原文对比）
 ⑤ 你确认 → 保存 / 或要求调整
```

## 番茄适配的编辑重点

番茄小说的编辑优先级：
1. **开头 200 字**：是否足够抓人？如果不是，重写
2. **段落长度**：是否有超过 3 句的段落？如果是，切短
3. **每章钩子**：结尾是否有足够的吸引力？
4. **信息密度**：是否有"水字数"的段落？删
5. **对话节奏**：对话是否推进了情节？如果不是，压缩或删除
