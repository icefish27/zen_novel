## 规则

- ═══ 开头结尾框面板
- ─── 只在分组需要时用
- 功法等级：入门 → 小成 → 大成 → 圆满
- 日常章极简，功法突破时才展开
- 面板前后各空一行
- 【】只用于面板标题
- 数字别太离谱。炼气期一次 +5 到 +20，金丹期一次 +1 到 +3

## 二、分阶段详细设定（原著精准对应）

### 1. 人界篇（韩立核心修炼阶段）

**原著官方明确划分**：以《梵圣真魔功》人界三层为基准，是所有炼体功法的通用模板

```
【第一重：铜皮铁骨】
对应法修：筑基后期 → 金丹期
特征：
- 皮肤如铜，骨骼如铁，普通刀剑砍上去只留白印
- 力量暴涨，可徒手捏碎精铁，一拳砸裂城墙
- 无需灵力加持，纯肉身就能硬抗金丹期法术
- 韩立进度：黄枫谷时期修炼至大成，凭此硬抗魔道修士

【第二重：银身】
对应法修：元婴期
特征：
- 皮肤呈现银色光泽，肉身强度堪比下品灵宝
- 可硬抗元婴期全力一击，断肢可缓慢再生
- 体内生成炼体真气，不用灵力也能飞行
- 韩立进度：乱星海时期修炼至大成，凭此击杀元婴后期修士

【第三重：金身】
对应法修：化神期
特征：
- 全身化为淡金色，肉身强度堪比中品灵宝
- 只要头颅和心脏不毁，就能快速恢复
- 可徒手撕裂空间，硬抗化神期天劫
- 韩立进度：人界末期修炼至大成，凭此飞升灵界
```

### 2. 灵界篇（炼体体系完善阶段）

**原著补充设定**：灵界体修有完整的官方等级，《梵圣真魔功》继续延伸

```
【金身境】
对应法修：化神 → 炼虚期
细分：初入金身、金身小成、金身大成、金身圆满
特征：
- 金身凝实，可化为金身法相，战力翻倍
- 普通灵宝无法伤其分毫，可硬抗炼虚期全力攻击

【玉骨境】
对应法修：合体期
特征：
- 全身骨骼化为温玉，坚不可摧
- 肉身可硬抗上品灵宝，哪怕只剩一根骨头也能重生
- 炼体真气化为罡气，可离体攻击
- 韩立进度：灵界中期修炼至大成，凭此硬抗合体后期修士

【不朽境】
对应法修：大乘期 → 渡劫期
特征：
- 肉身不朽，万古长存，不受凡俗岁月侵蚀
- 滴血重生，哪怕只剩一滴血也能重塑肉身
- 可徒手接下大乘期全力一击，硬抗天劫
- 韩立进度：灵界末期修炼至大成，凭此飞升仙界
```

### 3. 仙界篇（顶级炼体阶段）

**原著最终设定**：炼体与仙道法则融合

```
【真仙之躯】
对应法修：真仙期
特征：肉身转化为仙躯，吸收仙元之力淬炼

【金仙之躯】
对应法修：金仙期
特征：仙躯凝实，可硬抗金仙级仙术

【太乙仙躯】
对应法修：太乙期
特征：仙躯融入法则，可硬抗太乙级攻击

【大罗仙躯】
对应法修：大罗期
特征：肉身成道，万古不灭，可硬抗道祖一击

【道祖之躯】
对应法修：道祖期
特征：肉身与大道合一，一念之间可重塑肉身
```

## 三、《梵圣真魔功》专属设定（最经典、最适合爽文）

这是韩立的核心炼体功法，也是全网最知名的炼体体系，读者零理解成本，完美适配你的"做梦系统"：

1. **分层明确**：人界三层、灵界三层、仙界三层，每层对应一个法修大境界
2. **战力碾压**：同境界下，梵圣真魔功修炼者可碾压普通体修，越阶挑战法修
3. **特效炫酷**：每层突破都有明显的视觉变化（铜皮→银身→金身→玉骨）
4. **无灵力依赖**：纯靠肉身就能发挥战力，正好对应你"锁灵咒不破"的设定
