# 做梦系统 — AI 辅助小说写作

## 怎么用

告诉 AI 写第几章。比如：

> 写第一章

AI 自动读总纲 + 上一章，写完保存到 `output/chapters/`。

想改剧情，直接改 `小说总纲.md`。想改文风，改 `CLAUDE.md`。章节写出来直接打开文件编辑。

没了。

## 项目结构

```
novel/
├── CLAUDE.md           # 写作规则（AI 自动加载）
├── 小说总纲.md          # 蓝图（你要改就改这个）
├── output/chapters/    # 正文章节
├── 灵感收容/           # 参考材料
└── 搞笑小说原稿/        # 文笔学习素材
```
