# 禅机 — AI 辅助小说创作系统（番茄专版）

> Claude Code + DeepSeek V4 Pro 驱动的**番茄小说**平台向**系统流脑洞爽文**创作工作流。

## 平台聚焦

本系统专为 **番茄小说**（字节跳动免费阅读平台）设计，赛道锁定：

- **类型**：系统流 + 脑洞爽文
- **风格**：轻松搞笑、反套路、快节奏
- **受众**：男性用户，碎片化阅读场景
- **目标**：完读率 > 8%，获得推荐流量

## 设计哲学

不是"一键写书"工具，而是一套**可执行的创作工作流**。

- **Claude Code** — 调度中枢，理解意图、读写文件、调用 Sub-agent、维护进度
- **DeepSeek V4 Pro** — 百万上下文全书级一致性审查，伏笔追踪、设定矛盾检测
- **文件系统即数据库** — 所有产出结构化存储在 output/ 目录，零外部依赖

## 写作铁律

- **写的是小说，不是散文**。禁止堆砌华丽词藻、景物描写、氛围渲染
- 短句短段，段落 ≤ 3 句，一句话说不清就拆两句
- 对话优先：对话占比 40-60%，用对话推动剧情
- 每段必须推进情节或展现角色，没有过渡段
- 读起来像刷短视频，不用动脑就能跟上
- 故事趣味性第一：不好笑/不爽/不推剧情就删


## 写作工作流（6 阶段）

- **Phase 0** — 项目初始化：填写 checklist → 生成 novel.config.yaml
- **Phase 1** — 世界观构建：核心概念、世界设定、力量体系、时间线
- **Phase 2** — 角色设计：主角、反派、配角档案 + 关系图谱
- **Phase 3** — 大纲规划：故事结构、章节细纲、伏笔规划
- **Phase 4** — 正文写作：逐章输出，每章 2000-3000 字，黄金三章起手
- **Phase 5** — 质量审查：编辑润色 + DeepSeek 一致性检查
- **Phase 6** — 发布准备：标题优化、简介打磨、更新频率规划

## 核心标准

| 维度 | 标准 |
|------|------|
| 章节长度 | 2000-3000 字 |
| 段落 | 短段落 ≤ 3 句，尽量 1-2 句 |
| 对话占比 | 40-60%，推进情节 |
| 结尾 | 每章必留钩子（悬念/冲突升级/反转等） |
| 节奏 | 每 3 章小爽点，每 10 章大高潮 |
| 开局 | 黄金三章：困境 → 金手指 → 小高潮 |

## 技术栈

- **Claude Code** — 调度中枢 + 创作 Agent
- **DeepSeek V4 Pro** — 百万上下文一致性审查
- **Markdown + YAML** — 文件系统即数据库
