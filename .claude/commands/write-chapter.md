# write-chapter

写一章小说正文。约 2000 字。

## 写前必读（按顺序）

1. `output/tracking/chapter-index.md` — 最近 5 章概要，知道上一章结尾和钩子
2. `output/tracking/characters.md` — 本章会出场的角色当前状态
3. `output/tracking/open-threads.md` — 有没有可以顺手收回的伏笔
4. `小说总纲.md` — 本章对应段落（用户会告诉你是哪一段）
5. 上一章正文（`output/chapters/` 下找最新一章）— 延续文风

## 写作规则

严格遵循 CLAUDE.md。核心要点：

- 前 300 字出冲突。不准铺垫。
- 短句为主，每行≤17 字。句号断句，禁用"然而/此外/与此同时"。
- 心理描写用生理反应替代。不用"他心想""他感到一阵"。
- 系统提示用电报体/弹窗。不长篇说明。
- 每章结尾留钩子。
- 短剧五拍节奏：轻踩→加码→反制→引爆→冷收。
- 对话不写"XX说"，靠说话方式区分角色。
- 不打残不羞辱（前期）。打完收手。

## 输出格式

先输出正文，正文后附一段结构化标记（方便后续更新 tracking）：

```
---
## 本章概要
一句话，不超过 30 字。

## 角色状态变化
- 角色名：变化内容（修为突破/获得物品/关系变化/离开场景）
- 角色名：无变化则写"无"

## 新埋伏笔
- 伏笔内容
- 无则写"无"
---
```

## 字数

正文 1500-2000 字。不包含标记部分。
