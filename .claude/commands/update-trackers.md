# update-trackers

章节定稿后，更新所有 tracking 文件。不写正文，只维护状态。

## 输入

- 刚定稿的章节号 + 章节文件
- 章节末尾的结构化标记（本章概要、角色状态变化、新埋伏笔）

## 更新操作

### 1. chapter-index.md

在表格末尾追加一行：
```
| 00XX | 段名 | 一句话概要 | 2000 |
```
段名从总纲对应段取（如"小镇·拳馆"）。

### 2. characters.md

- 本章出场的角色，在"状态变化记录"下追加一条：`- 第X章：变化内容`
- 如果角色的"当前身份""修为""近期目标"变了，直接改对应字段
- 新角色：按模板新增一个角色块

### 3. timeline.md

追加关键事件行：
```
| 00XX | 事件描述 | 涉及角色 |
```

### 4. open-threads.md

- 新埋伏笔：在"未收回"下追加 `- [ ] 伏笔内容 | 第00XX章 | 待定`
- 已收回的伏笔：从"未收回"移到"已收回"，改标记为 `[x]`

## 注意

- 只追加，不删除已有内容
- 角色状态字段直接覆盖（不是追加）
- 更新完读一遍，确保格式一致
