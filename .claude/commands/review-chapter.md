# review-chapter

审一章已写的正文。找问题，给修改建议。

## 读什么

- 本章正文
- `output/tracking/characters.md` — 对比角色设定，看有没有串味
- `CLAUDE.md` — 对照规则检查

## 检查清单（逐项过）

### 1. AI 味检测
- 有没有"然而/此外/总而言之/与此同时/不仅如此"？→ 标出，建议删
- 有没有"他心想/他感到一阵/一股涌上心头/内心深处"？→ 标出，建议改生理反应
- 有没有大段景物描写（超 2 句）？→ 标出，建议砍
- 系统提示是不是电报体？如果不是 → 标出

### 2. 节奏检查
- 前 300 字有没有冲突/钩子？
- 五拍结构完整吗？（轻踩→加码→反制→引爆→冷收）
- 爽点密度够吗？一整章没一个爽点 → 标红
- 结尾有钩子吗？

### 3. 角色一致性
- 每个配角的说话方式是否和之前的章节一致？
- 主角行为是否符合"苟道流"人设？（不是不能打脸，是打脸后继续装）
- 有没有角色突然变聪明/变蠢？

### 4. 战力一致性
- 战力递进是否合理？（市井流氓<山匪<炼气<筑基<金丹）
- 杂灵根的人设不能灵力碾压同级

### 5. 对话检查
- 有没有两个人说话风格撞了？（听起来像同一个人）
- 对话后面有没有过度使用"XX说"？

