## 二、底层世界观

### 底层法则：太初道种

这个多元宇宙的底层逻辑是一条被称为**「太初道种」**的法则：

> **天地万物，皆从一颗「道种」开始。种子因缘和合，种下什么因，便收获什么果。**

#### 法则表现

| 现象 | 本世界观解释 |
|------|------------|
| 灵石矿脉 | 上古时期一颗「灵脉种子」经亿万年生长而成 |
| 功法传承 | 每种功法本质是一颗「法种」，需在识海中种下培育 |
| 法宝诞生 | 炼器的本质是用材料做培养基，让法宝从胚胎中生长出来 |
| 血脉觉醒 | 血脉是一颗沉睡的「种」，需要激活浇灌才能苏醒 |
| 剑意/道心 | 顿悟的本质是用自身经历做土壤，种下一颗概念之种 |

#### 设定意义

- **身份合理化**：主角的"种田"不是作弊，而是最古老的大道之路
- **力量体系统一**：传统修仙（自我修炼）+ 农场种植（大道力）并行
- **天花板拔高**：诸天终极秘密指向道种法则，QQ农场是其完美载体

### 势力体系

#### 东域：大秦皇朝
- **制度**：军功爵位制，修士按功勋晋升不按境界封王
- **修仙特点**：制式功法、军阵合击、帝国统一调配资源
- **对宗门态度**：敌对，"普天之下莫非王土"
- **核心伏笔**：秦皇持有一件残破的上古道种法器碎片，能微弱加速灵脉生长。他是当世唯一还略知道种法则皮毛的人

#### 西域：三宗四派

| 势力 | 定位 | 与主角关系 |
|------|------|-----------|
| **太虚宗** | 天道正统，崇尚清谈悟道，看不起实用主义 | 初期鄙视→被打脸→证道垫脚石 |
| **万剑宗** | 唯剑独尊，战力最强，行事霸道 | 强抢→被反杀→死敌 |
| **云岚宗** | 垄断西域七成丹药供应 | 初期合作→主角种出更好灵药→关系破裂 |
| **灵植派 ⭐** | 唯一研究灵药种植的宗门，被视为"没出息的农夫" | **重要盟友**：开派祖师是远古道种修士的记名弟子 |
| **天符门** | 符箓立派，需灵墨 | 忠实大客户 |
| **御兽山** | 御使灵兽，需大量灵草 | 忠实大客户 |
| **落星谷** | 占星推演，情报冠绝西域 | 中立情报源 |

### 主角起点：青云镇

> 一个被灵气遗弃的地方，却埋藏着让整个世界颤抖的种子。

- **位置**：东域·青州最南端，紧邻断天山脉余脉
- **现状**：灵脉千年前枯竭，只剩稀薄"残灵"。镇民半农半猎
- **主角身份**：许默，林家废物少爷，天生灵根残缺，刚被退婚
- **关键地标**：林家祖田——古灵脉遗址，千年前是林家先祖药田，如今寸草不生
- **资源起点**：祖田地下埋藏着"灵脉化石"和几颗远古「休眠种子」

## 四、力量体系

### 双轨等级

#### 轨道A：灵力修为（战力线）

灵徒 → 灵师 → 灵宗 → 灵王 → 灵皇 → 灵尊 → 灵圣 → 灵帝

每境分初中后三期。

#### 轨道B：农场等级（大道线）

| 农场等级 | 战力对标 | 解锁能力 | 对应剧情节点 |
|---------|---------|---------|------------|
| **灵土农场** | 灵徒~灵师 | 基础灵药种植、时间加速1000倍、守护傀儡 | 开局打脸退婚女 |
| **灵脉农场** | 灵宗~灵王 | 中品灵药、功法种植、灵脉种植、穿越低武 | 种出第一条新灵脉 |
| **道种农场** | 灵皇~灵尊 | 仙药、道种(剑意/丹道)、法宝种植、穿越中武 | 种出失传功法 |
| **诸天农场** | 灵圣 | 神药、世界种子、概念种植、穿越高武 | 种出一粒沙=一个世界 |
| **太初农场** | 灵帝+ | 法则种植，触及太初道种本源 | 终局 |

**核心设定**：灵力修为 ≠ 实际战力。灵宗境的许默，靠灵药+傀儡+灵兽，可以杀灵王。

### 升级规则

**许默的双重升级路径**：
- **修为突破**：不靠打坐，靠本源精华灌溉（种植高阶作物→收获时萃取）
- **农场突破**：种植总量达标 + 种出「关键解锁作物」+ 完成「诸天助农任务」

**卡级点（剧情驱动力）**：

| 农场突破 | 所需作物 | 种子来源 | 剧情任务 |
|---------|---------|---------|---------|
| →灵脉农场 | 还魂草 | 南域莽荒远古遗迹 | 第一次出门冒险 |
| →道种农场 | 悟道茶种 | 斗破苍穹副本 | 第一次穿越 |
| →诸天农场 | 世界树幼苗 | 仙逆/遮天副本 | 接触顶尖战力 |
| →太初农场 | 太初道种碎片 | 北域古族+多副本收集 | 主线大高潮 |

### 六大种植能力

| 能力 | 解锁等级 | 说明 |
|------|---------|------|
| 灵药种植 | 灵土农场 | 十年灵参→千年灵参，批量打破稀缺铁律 |
| 功法种植 | 灵脉农场 | 残卷→完整版，普通版+肥料→变异进化版 |
| 灵脉种植 | 灵脉农场 | 枯竭之地种下灵脉种子→新生灵脉 |
| 法宝种植 | 道种农场 | 碎片→完整法宝，材料→成品 |
| 概念种植 | 道种农场 | 剑意→剑道感悟，丹方→丹道真解 |
| 世界种植 | 诸天农场 | 一粒沙→小世界，一个念头→秘境 |

### 战力公式

**凡人**：境界 × 功法 × 法宝 × 战斗经验

**许默**：(境界+本源强化)×(种植神功)×(种植至宝)×(灵药堆满属性)+(傀儡+灵兽+阵法) = 不讲道理的实际战力

### 力量限制

| 限制 | 说明 |
|------|------|
| 种子依赖 | 种不出没种子的东西，稀有种子是核心瓶颈 |
| 农场沉睡期 | 每升一级后进入沉睡期，只能维持基本种植 |
| 本源转化率 | 灵土期1:1，灵脉期3:1，道种期10:1，诸天期100:1 |
| 战斗短板 | 初期靠灵药+傀儡+灵兽，中期通过剑意种植补足 |
| 本质暴露风险 | 农场本质暴露会引来全大陆觊觎，贯穿始终 |
| 本源反噬 | 强行越级战斗后进入虚弱期 |

## 十、节奏与写作标准

### 核心数据

| 维度 | 标准 |
|------|------|
| 每章字数 | 2000-3000字 |
| 每段 | ≤3句，尽量1-2句 |
| 对话占比 | 40-60%，用对话推动剧情 |
| 小高潮 | 每3-5章一次 |
| 大高潮 | 每30章一次 |
| 每章结尾 | 必留钩子 |

### 黄金三章公式

| 章 | 功能 | 核心动作 |
|----|------|---------|
| 第1章 | 困境+拉仇恨 | 300字内建立处境，冲突，设反派 |
| 第2章 | 金手指登场 | 系统激活，简要介绍，初步使用 |
| 第3章 | 小高潮+钩子 | 用系统逆袭打脸，埋悬念结尾 |

### 钩子类型
- 悬念型 / 冲突升级型 / 新信息型 / 反转型 / 选择题型

### 写作铁律
- **写的是小说，不是散文**。禁止堆砌华丽词藻、景物描写、氛围渲染
- 短句短段，一句话说不清就拆两句
- 对话优先：能对话推进的，不用叙述
- 每段必须推进情节或展现角色，没有过渡段
- 读起来像刷短视频，不用动脑就能跟上
- **趣味性第一**：不好笑/不爽/不推剧情就删

### 去AI味规则
- 句式破型，不要每句主谓宾完整
- 少用"然而/但是/因此"等连接词
- 形容词写完后砍一半
- 禁止段落/章节结尾出现"这意味着""从此""这让XX意识到"
- 段落不要均匀分布，突然1句的段落制造冲击
- 主角不要口头禅（木偶化），配角可以用口头禅区分

### 合理擦边规则（男频）
- 擦边是为了"会心一笑"，不是写色情
- "暗示比明说有效"：点到为止，留白让读者脑补
- 推荐方式：暧昧对话、系统恶趣味、身份反差、系统搞事
- 底线：不能有性行为描写，不涉未成年人，不涉强迫
- 暧昧到「牵手、拥抱、意外身体接触」为止
- 擦边戏码必须剧情需要，不是为了擦边而擦边
